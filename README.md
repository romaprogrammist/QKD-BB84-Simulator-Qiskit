# QKD BB84 Simulator Qiskit
Реализация протокола квантового распределения ключей BB84 с детальным анализом ошибок (QBER) с использованием библиотеки IBM Qiskit.

**Углубленная реализация протокола квантового распределения ключей BB84 с детальным анализом квантового коэффициента ошибок (QBER) с использованием библиотеки IBM Qiskit.**

---

## Обзор и Научная Значимость

Проект представляет собой программный симулятор протокола **BB84** — первой реализации квантового распределения ключей. Он демонстрирует **информационно-теоретическую безопасность** QKD, основанную на теореме о неклонировании и принципе возмущения измерения.

**Значимость:**
1.  **Обнаружение Взлома:** QKD позволяет **гарантированно обнаружить** любую попытку прослушивания, что делает его критически важным для будущих систем кибербезопасности.
2.  **Верификация QBER:** Проект фокусируется на расчете **QBER** — основного показателя качества канала. Его превышение однозначно сигнализирует о компрометации.

## Технологический Стек

* **Основной язык:** Python 3.10+
* **Квантовая платформа:** Qiskit (IBM Quantum Information Software Kit)
* **Симулятор:** `qiskit_aer.AerSimulator` (для точного моделирования квантовых измерений).
* **Библиотеки:** NumPy (для эффективной генерации случайных данных и векторизации расчетов).

---

## Детализация Реализации и Методология

Симулятор реализован с помощью стандартных квантовых гейтов Qiskit (см. файл **`BB84_Sim.py`**):

1.  **Базисы и Гейты:** Кодирование информации осуществляется в двух неортогональных базисах (Стандартный/Z и Диагональный/X), что является краеугольным камнем протокола.
2.  **Моделирование Атаки (Функция `eavesdrop_on_qubits`):** Внедрение Евы моделируется через функцию, которая совершает измерение в случайном базисе, **неизбежно** внося пертурбации в квантовое состояние, что и приводит к росту QBER.
3.  **Обнаружение Взлома:** Расчет QBER (`calculate_qber`) позволяет участникам канала обнаружить вмешательство и отбросить ключ, сохраняя информационную безопасность.

## Сценарии и Результаты (Пример Вывода)

Проект запускает два ключевых сценария для верификации протокола.

### СЦЕНАРИЙ 1: Квантовый канал БЕЗ ЕВЫ (Контрольный)
* Ожидаемый QBER: Близко к 0 (идеальный канал).

### СЦЕНАРИЙ 2: Квантовый канал С ЕВОЙ (Анализ безопасности)
* Ожидаемый QBER: Рост частоты ошибок до уровня, превышающего порог обнаружения (обычно ~11-12.5%).
* **Пример вывода кода (`BB84_Sim.py`):**
    ```
    ...
    Отобранный ключ Боба:  [0 1 0 0 1 0 1 1 1 0]
    Частота ошибок (QBER): 0.20
    !!! ОБНАРУЖЕНА ЕВА! Попытка взлома. Ключ не будет использован. !!!
    ```

## Инструкция по Запуску

1.  **Установка зависимостей:** `pip install qiskit-aer numpy`
2.  **Запуск:** Запустите основной файл **`BB84_Sim.py`**. Программа выведет результаты симуляции QBER для двух сценариев (с Евой и без нее) и сделает вывод о безопасности ключа.
