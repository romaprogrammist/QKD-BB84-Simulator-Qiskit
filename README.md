# Улучшенный Программно-Аппаратный Симулятор BB84
## Академическая Версия v3.5
 
Программная модель протокола квантового распределения ключей BB84 на базе библиотеки IBM Qiskit с интерактивным графическим интерфейсом и полной физической симуляцией оптического волокна, квантовых детекторов (SPAD/SNSPD) и комплексного анализа безопасности против активных атак перехвата.

---

## 🔬 Обзор и Научная Значимость

Данный проект представляет собой интегрированную программно-аппаратную симуляционную платформу квантового распределения ключей BB84, которая объединяет:

1. **Квантовые вычисления уровня схем** — точная симуляция с использованием IBM Qiskit и оптимизированного симулятора Stabilizer из qiskit-aer
2. **Физическую моделизацию оптических каналов** — реалистичное затухание волокна, темновые отсчеты детекторов, послеимпульсы (afterpulsing)
3. **Криптографический анализ** — многоитерационная коррекция ошибок (Cascade), усиление секретности матрицами Тёплица (Privacy Amplification)
4. **Интерактивный интерфейс планирования** — расчет характеристик сетей QKD на реальные расстояния с визуализацией граница Пирандолы-Лоренцы-Оттавиани-Бэйнса (PLOB)

Симулятор наглядно демонстрирует информационно-теоретическую безопасность квантовой криптографии, основанную на неколируемости квантовых состояний и неизбежности обнаружения любого перехвата.

### Фундаментальные Принципы

1. **Теорема о запрете клонирования (No-cloning theorem)** — невозможность создания идеальной копии неизвестного квантового состояния гарантирует невозможность скрытого перехвата без нарушения синхронизации

2. **Коллапс волновой функции при измерении** — любое несанкционированное вмешательство Евы (подслушивание) неизбежно приводит к ошибкам (QBER > 11%), которые обнаруживаются Алисой и Бобом

### Основные Направления Исследования

- **Детекция вторжений (IDPS)**: Использование непрерывного мониторинга квантового коэффициента ошибок (QBER) как индикатора активной атаки с порогом Шора-Прескилла (11%)

- **Физическое моделирование волоконной оптики**: Симуляция аппаратных дефектов, затухания сигнала, темновых отсчетов SPAD/SNSPD датчиков и послеимпульсов

- **Криптографическая устойчивость к атакам**: Анализ трех классов атак перехвата (Intercept-Resend, угол 22.5°, квантовая память) с оценкой информационной утечки Евы

- **Сетевое планирование QKD**: Расчет скорости генерации секретного ключа (SKR) для произвольных расстояний с учетом физических параметров детекторов и источников

## 🚀 Ключевые Особенности Симулятора v3.5

### Режим 1: Симуляция BB84 с Моделированием Атак

В отличие от ранних идеализированных версий, симулятор v3.5 реализует полный криптографический цикл:

#### 1. Реалистичный Деполяризующий Канал

Внедрена строгая математическая модель симметричной деполяризации кубитов с заданной вероятностью. Каждый кубит может претерпеть одну из трёх квантовых ошибок Паули с равной вероятностью:

- **Битовый переворот** (Bit-flip, оператор `X`)
- **Фазовый переворот** (Phase-flip, оператор `Z`)
- **Смешанная ошибка** (Bit-Phase flip, оператор `Y`)

#### 2. Продвинутые Стратегии Подслушивания Евы (Eve)

##### 📍 Стандартная атака (Intercept-Resend)
Ева измеряет кубиты в случайном базисе BB84 и отправляет Бобу заново подготовленные состояния. В среднем вносит QBER ≈ 25% при полном перехвате.

##### 📍 Промежуточная атака Брейдбарта (22.5°)
Ева проецирует состояния кубитов на оси, повернутые на угол π/8, пытаясь собрать частичную информацию. Вносит QBER ≈ 14.6% при частичном знании базисов.

##### 📍 Когерентная атака с квантовой памятью
Моделирует уязвимость хранения. Ева запутывает кубиты Алисы с вспомогательными ancilla-кубитами через CNOT-ворота и отложено (после объявления базисов) проводит измерение, максимизируя утечку информации.

#### 3. Двухэтапная Классическая Постобработка

##### 🔧 Многоитерационная коррекция ошибок (Cascade)
Боб и Алиса сравнивают паритеты блоков с динамической бинарной перестановкой (binary search). Алгоритм автоматически масштабируется на основе оценки QBER, обеспечивая полную синхронизацию после нескольких итераций.

##### 🔐 Усиление секретности (Privacy Amplification)
Финальный согласованный ключ сжимается через универсальное хэширование матрицами Тёплица согласно границе Шора-Прескилла. Вся перехваченная Евой информация полностью нивелируется.

### Режим 2: Планирование и Анализ Сетей QKD

Полнофункциональный инструмент для проектирования квантово-защищенных каналов связи на реальные расстояния:

#### Физическое Моделирование Линии ВОЛС
- **Затухание оптического волокна** — $T = 10^{-\alpha L / 10}$ дБ
- **Эффективность регистрации** — произведение пропускания волокна, квантовой эффективности детектора (SPAD/SNSPD) и среднего числа фотонов
- **Темновые отсчеты** — моделирование автоионизации в SPAD и термоэлектронной эмиссии в SNSPD

#### Расчет Метрик Безопасности
- **Физический QBER**: $\text{QBER}(\text{phys}) = \frac{P_{\text{dark}}}{2(P_{\text{signal}} + P_{\text{dark}})} + \epsilon_{\text{optics}}$
- **Соотношение сигнал/шум (SNR)** для оценки пропускной способности
- **Скорость генерации секретного ключа (SKR)** — $r_{\text{SKR}} = f_{\text{rep}} \cdot P_{\text{click}} \cdot 0.5 \cdot (1 - 2H_2(e) - \text{leak}_{\text{EC}})$ бит/сек

#### Визуализация Границ Достижимости
- График зависимости SKR от расстояния с наложением теоретического предела Пирандолы-Лоренцы-Оттавиани-Бэйнса (PLOB)
- Динамическая оценка максимального расстояния для достижения положительной SKR с заданными параметрами оборудования

# Коэффициент квантовых ошибок в битах (QBER)
QBER = (количество ошибок) / (длина просеянного ключа)

# Критический порог Шора-Прескилла для BB84
QBER_threshold_ideal = 0.11  # 11% для идеального канала

# Секретность ключа после усиления (Privacy Amplification)
secret_key_entropy = 256 bits  # SHA-256

# Физический QBER с учетом детекторов и волокна
QBER_phys = (P_dark / (2*(P_signal + P_dark))) + Optics_Error

# Скорость генерации секретного ключа
SKR = f_rep * P_click * 0.5 * max(0, 1 - 2*H2(QBER) - leak_EC) [бит/сек]

## 🔐 Криптографическая Безопасность

### Информационно-Теоретическая Стойкость

Безопасность BB84 основана на **информационно-теоретической криптографии** (unconditionally secure):

- Стойкость **не зависит** от вычислительных ресурсов противника
- Даже гипотетический квантовый компьютер **не может** нарушить безопасность BB84
- Любая попытка перехвата **гарантированно обнаруживается** через мониторинг QBER

### Функция Privacy Amplification через Матрицы Тёплица

```python
import hashlib
import numpy as np

# Исходный просеянный ключ (частично скомпрометирован Евой)
sifted_key = np.array([0, 1, 0, 0, 1, 1, ...])

# Универсальное хэширование матрицей Тёплица
# Генерируется случайная матрица m×n по алгоритму Hayashi-Tsurumaru
# compressed_key = Toeplitz_matrix · sifted_key (mod 2)

# Финальное криптографическое усиление (SHA-256)
final_key = hashlib.sha256(bytes(compressed_key)).hexdigest()

# Результат: полностью секретный 256-битный ключ
# (любое частичное знание Евы полностью нивелировано лавинным эффектом SHA-256)
```

### Граница Шора-Прескилла

Граница Шора-Прескилла
​Оценка длины секретного ключа после усиления секретности (Privacy Amplification) определяется через энтропию бинарного симметричного канала $H_2(e)$:

$$R \geq 1 - 2 H_2(\text{QBER})$$
Где $H_2(p) = -p \log_2(p) - (1-p) \log_2(1-p)$ — двоичная энтропия Шеннона.

Максимальная оставшаяся информация у Евы после усиления секретности $I_{\text{Eve}}$ ограничивается следующим образом:

$$I_{\text{Eve}} \leq \text{sifted len} \cdot (2 H_2(\text{QBER}))$$



При $\text{QBER} < 11.0\%$ (точнее $\approx 11.04\%$) значение $1 - 2H_2(\text{QBER}) > 0$, что гарантирует возможность выделения строго секретного ключа, о котором у Евы будет экспоненциально мало информации ($I_{\text{Eve}} \to 0$ относительно длины итогового ключа).

### Квантовые Каналы и Эффекты Шума

- **Depolarizing Channel**: Kraus operators {I, X, Y, Z} с вероятностью p каждого
- **Bit-flip Channel**: Ошибки моделируются через оператор Паули X
- **Phase-flip Channel**: Ошибки моделируются через оператор Паули Z
- **Afterpulsing в SPAD**: Временное окно мертвого времени детектора 10–100 нс
