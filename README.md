# Улучшенный Программно-Аппаратный Симулятор BB84
## Академическая Версия v3.1

Программная модель протокола квантового распределения ключей BB84 на базе библиотеки IBM Qiskit с интерактивным GUI-интерфейсом, многопоточной симуляцией физических уязвимостей и классической постобработкой.

---

## 🔬 Обзор и Научная Значимость

Данный проект представляет собой программно-аппаратную симуляционную модель квантового распределения ключей (QKD) по протоколу BB84, разработанную с учетом рекомендаций и физических ограничений реального телекоммуникационного оборудования.

Симулятор наглядно демонстрирует информационно-теоретическую безопасность квантовой криптографии, основанную на фундаментальных принципах квантовой механики:

### Фундаментальные Принципы

1. **Теорема о запрете клонирования (No-cloning theorem)** — невозможность создания идеальной копии неизвестного квантового состояния.

2. **Коллапс волновой функции при измерении** — любое несанкционированное вмешательство Евы (подслушивание) неизбежно разрушает суперпозицию состояний, что обнаруживается легитимными пользователями (Алисой и Бобом) по росту показателя QBER.

### Основные Направления Исследования

- **Детекция вторжений (IDPS)**: Использование непрерывного мониторинга квантового коэффициента ошибок (QBER) как активного триггера обнаружения компрометации канала.

- **Устойчивость в условиях шума**: Моделирование аппаратных дефектов и затухания сигнала в волоконно-оптической линии связи (ВОЛС) без участия Евы.

- **Квантовая устойчивость финансовых систем**: Анализ применимости QKD для превентивной защиты межбанковских транзакций Цифрового белорусского рубля (ЦБР) от атак класса «Harvest now, decrypt later» (перехват данных сейчас для последующей дешифрации на квантовых компьютерах будущего).

## 🚀 Ключевые Особенности Симулятора v3.1

В отличие от ранних идеализированных моделей, версия v3.1 реализует глубокую физическую симуляцию процессов квантового канала:

### 1. Реалистичный Деполяризующий Канал

Внедрена строгая математическая модель симметричной деполяризации кубитов в оптическом волокне. С заданной слайдером вероятностью `p` кубит подвергается воздействию одного из трех операторов Паули с равной вероятностью `p/3`:

- **Битовый переворот** (Bit-flip, оператор `X`)
- **Фазовый переворот** (Phase-flip, оператор `Z`)
- **Смешанная ошибка** (Bit-Phase flip, оператор `Y`)

### 2. Продвинутые Стратегии Подслушивания Евы (Eve)

#### 📍 Стандартная атака (Intercept-Resend)
Ева измеряет кубиты в случайном базисе BB84 и отправляет Бобу заново подготовленные состояния. Вносит в канал QBER ≈ 25%.

#### 📍 Промежуточная атака Брейдбарта (22.5°)
Ева проецирует состояния кубитов на оси, повернутые на угол π/8 с помощью гейта `R_y(-π/4)`, пытаясь собрать частичную информацию при сниженном QBER. Средний QBER Боба стремится к теоретическим `sin²(π/8) ≈ 14.6%`.

#### 📍 Когерентная атака с квантовой памятью
Моделирует запуск уязвимости хранения. Ева не измеряет кубиты сразу (сохраняя суперпозицию), а транслирует их Бобу, наводя лишь фазовый шум хранения (`Z`-ошибки). Измерение Евой своей памяти происходит строго после публичного раскрытия базисов на этапе sifting, что дает ей 100% точность считывания просеянного ключа.

### 3. Двухэтапная Классическая Постобработка

#### 🔧 Дихотомическое исправление ошибок
Боб и Алиса сравнивают паритеты блоков фиксированной длины (K=4). При несовпадении четности запускается эффективный бинарный рекурсивный поиск бита ошибки. Алгоритм устойчив к ложным срабатываниям, но наглядно демонстрирует фундаментальное ограничение однопроходных проверок — невидимость блоков с четным числом ошибок.

#### 🔐 Усиление секретности (Privacy Amplification)
Финальный согласованный ключ хэшируется с помощью алгоритма SHA-256. Лавинный эффект хэш-функции полностью уничтожает любое частичное знание Евы о битах ключа, сжимая его до гарантированно секретного 256-битного криптографического ключа.

## 📈 Научные Метрики и Анализ

### Ключевые Показатели Производительности

```python
# Коэффициент квантовых ошибок в битах (QBER)
QBER = (количество ошибок) / (длина просеянного ключа)

# Критический порог (теоретический)
QBER_threshold_ideal = 0.11  # 11% для идеального канала

# Секретность ключа после усиления (Privacy Amplification)
secret_key_entropy = 256 bits  # SHA-256
```

## 🔐 Криптографическая Безопасность

### Информационно-Теоретическая Стойкость

Безопасность BB84 основана на **информационно-теоретической криптографии** (unconditionally secure):

- Стойкость **не зависит** от вычислительных ресурсов противника
- Даже квантовый компьютер **не может** нарушить безопасность BB84
- Любая попытка перехвата **гарантированно обнаруживается**

### Функция Privacy Amplification

```python
import hashlib

# Исходный просеянный ключ (частично скомпрометирован Евой)
sifted_key = [0, 1, 0, 0, 1, 1, ...]

# Универсальное хэширование (SHA-256)
final_key = hashlib.sha256(bytes(sifted_key)).hexdigest()

# Результат: полностью секретный 256-битный ключ
# (любое частичное знание Евы полностью нивелировано)
```
